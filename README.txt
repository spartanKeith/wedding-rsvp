JONATHAN & COLYN RSVP WEBSITE

FILES
- index.html: Website structure and content
- styles.css: Design, layout, colors, mobile responsiveness
- script.js: Countdown, FAQ, navigation, RSVP form behavior
- google-apps-script.js: Code to connect the RSVP form to Google Sheets
- assets/: Place your images here

HOW TO OPEN
1. Open index.html in your browser.
2. For local XAMPP testing, copy this whole folder to htdocs.
3. Visit: http://localhost/jonathan_colyn_rsvp_website/

IMAGES TO REPLACE
Place your real images in the assets folder using these names:
- Villa+deste.webp      (cover / landing image)
- venue-photo.webp      (venue image)

IMPORTANT: The PDF mentioned Villa+d'este.webp. File names with apostrophes can cause path issues, so this website uses Villa+deste.webp without the apostrophe.

RSVP GOOGLE SHEETS SETUP
1. Create a Google Sheet.
2. Click Extensions > Apps Script.
3. Paste the content of google-apps-script.js.
4. Deploy > New deployment > Web app.
5. Execute as: Me.
6. Who has access: Anyone.
7. Copy the Web app URL.
8. Open script.js and replace:
   PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE
   with your Web app URL.
